# Super Mario Galaxy — Promotional Landing Page

Landing page temática inspirada em **Super Mario Galaxy**, criada como estudo de front-end para divulgação de uma produção cinematográfica.

## Objetivo

Criar uma experiência promocional com forte identidade visual, animações e componentes interativos, explorando uma estética espacial inspirada no universo de Mario.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GSAP
- GSAP ScrollTrigger
- particles.js

## Destaques

- Hero temático
- Fundo e efeitos de partículas
- Animações com GSAP
- Efeitos acionados pelo scroll
- Seção de personagens
- Área de trailers com carrossel
- Seção de estreia

## Estrutura

```text
.
├── assets/
├── css/
├── docs/
├── js/
├── prints/
├── DESIGN.md
└── index.html
```

## Aprendizados

O projeto permitiu praticar:

- integração de bibliotecas de animação;
- composição de efeitos visuais;
- criação de seções promocionais interativas;
- organização de um projeto front-end em múltiplos arquivos;
- documentação de decisões visuais.
